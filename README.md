# 🔐 Security Scanner (Python)

A beginner-friendly Python security scanner inspired by Burp Suite.

## 🚀 Features
- Missing Security Headers Detection
- Reflected XSS Testing
- Error-based SQL Injection Detection

## 🛠 Technologies Used
- Python 3
- Requests library

## ▶️ How to Run

```bash
git clone https://github.com/YOUR_USERNAME/security-scanner.git
cd security-scanner
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 main.py
